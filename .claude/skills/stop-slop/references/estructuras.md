# Estructuras para evitar

## Contrastes binarios

Crean drama falso. Decir la idea directo.

| Patrón | Problema |
|--------|----------|
| «No porque X. Porque Y.» / «No por X, sino por Y.» | Giro anunciado |
| «[X] no es el problema. [Y] sí.» | Reencuadre de fórmula |
| «La respuesta no es X. Es Y.» | Giro predecible |
| «Parece X. En realidad es Y.» | Planteamiento y revelación |
| «La pregunta no es X. Es Y.» | Desvío retórico |
| «No es X, es Y» / «No se trata de X, sino de Y» | Contraste mecánico |
| «Más que un X, es un Y» | La misma fórmula |
| «deja de ser X y pasa a ser Y» | Transformación falsa |
| «no significa X, sino Y» | Negar para luego afirmar |
| «no solo X, sino también Y» | Suma disfrazada |

**En cambio:** decir Y. «El problema es Y.» Quitar la negación.

## Listas de lo que algo no es

Decir lo que algo no es antes de decir lo que es.

| Patrón | Problema |
|--------|----------|
| «No es un X… No es un Y… Es un Z.» | Suspenso por negación |
| «No fue X. No fue Y. Fue Z.» | Lo mismo en pasado |
| «Sin apps. Sin claves. Sin enredos.» | La versión de folleto |

**En cambio:** decir Z. El lector no necesita la pista de despegue.

## Fragmentos dramáticos

| Patrón | Problema |
|--------|----------|
| «[Sustantivo]. Eso es todo. Ese es el [algo].» | Simpleza actuada |
| «X. Y Y. Y Z.» | Drama entrecortado |
| «Esto lo cambia todo. [Palabra].» | Revelación artificial |
| «Escaneas. Reportas. Avisamos.» | Tres golpes de eslogan |

**En cambio:** frases completas. Que pese el contenido, no la presentación.

## Preámbulos retóricos

| Patrón | Problema |
|--------|----------|
| «¿Y si te dijera que…?» | Pose socrática |
| «¿El resultado? …» / «¿La clave? …» | Pregunta respondida al instante |
| «A lo que voy es:» | Adelanto que sobra |
| «Piénsalo:» | Condescendiente |
| «Y está bien.» | Permiso que nadie pidió |

**En cambio:** decir la idea. El lector saca sus conclusiones.

## Construcciones de fórmula

| Patrón | Problema |
|--------|----------|
| «Para cuando X, yo ya Y.» | Plantilla narrativa |
| «X que no es Y» | Indirecto. Decir «X está dañado» |
| «…, permitiendo / garantizando / logrando…» al final | Gerundio de posterioridad que infla |

## Cosas que actúan como personas

Los reportes no «se convierten» en ayuda. Las decisiones no «surgen». Una persona hace algo.

| Patrón | Problema |
|--------|----------|
| «el reporte se convierte en ayuda» | El reporte no hizo nada. Alguien ayudó. |
| «la decisión surge» | Alguien decide. |
| «la cultura cambia» | La gente cambia lo que hace. |
| «los datos nos dicen» | Alguien los lee y saca una conclusión. |
| «el mercado premia» | Los compradores pagan. |

**En cambio:** nombrar a la persona. Si no hay una, usar «tú» o «usted».

**Excepción:** el sistema sí actúa. «El sistema le manda el WhatsApp a la familia» es exacto.

## Narrador lejano

| Patrón | Problema |
|--------|----------|
| «Nadie diseñó esto.» | Observación sin cuerpo |
| «Esto pasa porque…» | Voz de conferencia |
| «Por eso es que…» | Lo mismo |
| «Las personas tienden a…» | Sociólogo de sofá |

**En cambio:** meter al lector. «Nadie se monta en la moto pensando en un accidente» le gana a «las personas no prevén los accidentes».

## Pasiva con «ser»

| Patrón | Arreglo |
|--------|---------|
| «X fue creado» | Decir quién lo creó |
| «Es sabido que» | Decir quién lo sabe |
| «Se cometieron errores» (para esconder) | Decir quién |
| «La decisión fue tomada» | Decir quién decidió |

La pasiva con «se» que describe un proceso («los datos se cifran», «el reporte se cierra a las 24 horas») es natural y se queda.

## Arranques para evitar

| Patrón | Arreglo |
|--------|---------|
| «Lo que hace esto difícil es…» | «La dificultad es…» o nombrarla |
| Párrafos que empiezan con «Entonces,» o «Así que,» | Empezar con el contenido |
| Frases que empiezan con «Mira,» | Quitarlo |
| «Además,» al inicio de cada párrafo | Variar o quitar |

## Ritmo

| Patrón | Arreglo |
|--------|---------|
| Listas de tres | Dos o una |
| Preguntas respondidas al instante | Quitar la pregunta |
| Cada párrafo termina con remate | Variar los finales |
| Rayas (—) | Quitarlas. Comas, puntos o paréntesis. |
| Frases cortas apiladas | No amontonar golpes |
| «No siempre. No perfecto.» | Duda disfrazada de consuelo |

## Palabras

| Patrón | Problema |
|--------|----------|
| Extremos perezosos (todo, siempre, nunca, todos, nadie) | Autoridad falsa. Usar lo concreto. Excepción: reglas de seguridad ciertas. |
| Adverbios en -mente, «realmente», «simplemente», «sin duda» | Énfasis vacío. Ver frases.md. |
| Comodines (clave, crucial, fundamental, robusto, potenciar, integral, innovador) | Suenan a IA. Decir el dato. |
| Mayúscula En Cada Palabra en títulos | Calco del inglés. Solo la primera. |
| Sin signo de apertura (¿ ¡) | Error. Ponerlo siempre. |
